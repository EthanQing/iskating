# iSkating Coach 当前功能全量清单

更新时间：2026-07-20。本文以当前代码为准，供重新规划信息架构、界面和使用流程使用；它描述“已经存在”的能力，不等同于产品规划。

## 产品构成

| 层 | 既有能力 | 依赖 |
|---|---|---|
| Windows 桌面端 | Qt 界面、视频播放、本机低帧率 AI、训练操作、历史与报告 | `iskating.exe` |
| 业务服务 | 登录、人员、训练、任务与报告数据 | FastAPI + PostgreSQL |
| Ubuntu worker | 12 路完整帧率 DeepStream 分析、分块与恢复 | Ubuntu + Docker + NVIDIA + NAS |

桌面端不直接连接 PostgreSQL；摄像头与采集偏好保存在本机 QSettings。

## 主界面与全局操作

- 左侧页签：**运动员检测**（实时工作区）、**训练历史与分析**（记录、报告、复盘）、**动作纠正与建议**（趋势与建议）。
- 顶栏：模块、训练状态、日期时间、系统状态、AI 模型状态、数据库状态；支持侧边栏折叠和全屏。
- 右侧快捷栏：开始采集、暂停、停止、保存记录、系统设置。
- AI 状态可显示初始化、就绪、等待视频帧、D3D 取帧失败、YOLO 推理失败、运行中人数。

## 视频、采集与任务

### RTSP 摄像头

- 最多 12 路相机；每路可配置 IP、端口、预览/主码流路径、名称、机位参数、轨迹开关及冰面四点标定。
- 支持预览/主码流、主码流失败回退预览、UDP 优先/TCP 回退、断流退避重连与长时间断流提示。
- 小窗双击可切主视图；系统设置可逐路执行连通测试，显示地址、协议、打开/首帧耗时、分辨率、帧率与错误阶段。

### 本地视频

- **导入视频**支持 mp4、mov、avi、mkv、m4v、wmv、flv、webm。
- 导入前验证文件、视频轨、时长、seek、D3D11VA 和首帧；支持播放、暂停、停止、seek、变速、逐帧。
- 当前导入动作创建 `offline_import` 任务并切换主播放器；保存时只记录原文件引用，不复制视频。
- 本机 AI 要求 D3D11VA/D3D11 帧；视频可播放不保证可供 AI 推理。

### 当前语义冲突（重要）

- **开始采集**当前是“实时训练采集会话”按钮：RTSP 模式启动机位；已导入视频时会复用该播放流做本机低帧率 AI。
- 它不是单视频后台完整分析按钮。
- 当前没有 Windows 上“选择单个视频后自动逐帧跑完整文件并生成完整离线结果”的独立产品流程。

### 完整分析与任务中心

- **完整分析**是 12 路 `nas://` manifest 的完整帧率批处理；可创建批次/运行、查看每路进度/吞吐/ETA/错误、取消、重试、激活结果版本。
- Ubuntu DeepStream worker 逐帧检测，按轨迹触发 ReID，按 10 秒 gzip JSONL 分块登记 SHA256；Windows 不运行该 worker。
- 回放可显示已完成区间；缺口会清空框。
- **任务中心**统一显示单视频导入与完整批次的状态、进度、错误、暂停/继续/取消和关联 session。

## AI、身份与指标

- Windows 本机：YOLO26x 人体检测 + PersonViT/MSMT17 ReID；默认检测阈值 0.35，默认每路约 5 FPS，可配置目标 FPS、最大流数、自动降级与 fast/balanced/high。
- 输出检测框、置信度、trackId、身份状态与身份置信度；无样本时也应显示“未识别”框。
- 人工绑定可将 track 绑定到当前训练参与者或取消绑定。
- ReID 样本库：上传/查看/删除运动员图片，本机生成 embedding，服务端保存样本、向量、模型和预处理版本。
- 四点标定后可保存二维米制轨迹、瞬时/平滑速度与算法版本。
- 关节角/角速度有数据表、查询与报告接口；当前新实时流程不生成关键点/骨架、自动动作计数或自动技术评分，旧数据仅兼容读取。

## 训练前置管理

- **训练上下文**：选择运动员、教练、比赛、场次、参赛关系、动作标准。
- **人员管理**：运动员档案（体格、专项、水平、伤病、目标等）、教练档案、教练-运动员关系、归档；归档不删除历史。
- **比赛管理**：比赛、场次、参赛关系、号码、道次、排序、成绩和名次的新增、编辑、归档、查询。
- **动作标准**：类别、目标次数/分数、组数、休息、阈值、权重、最低值、问题提示、参考视频与版本。

## 训练记录、历史与报告

- 保存 session 时间、时长、机位、视频来源、人员、动作标准版本、检测摘要、参与者、轨迹、速度、视频资产与任务关联。
- 历史组合检索：运动员、教练、比赛、场次、动作、来源、日期、分数、关键词；支持分页及按时间/分数/时长排序。
- 历史卡片：回看视频、复盘校准、姿态轨迹、教练批注、导出报告。
- 动作明细跨 session 检索：人员、动作、比赛、来源、有效性、复核、分数、片段时间、错误关键词；可导出 CSV/XLSX。
- 复盘：人工新增动作、修正起止时间/有效性/分数/错误/反馈/批注；统计遵循“人工优先、AI 原始保留”。
- 轨迹/姿态回顾：按参与者、时间、机位、track 查询；可定位本地视频并导出 CSV/XLSX。
- 单 session 可导出 Markdown、CSV、PDF；报告中心按日期、参与者、训练内时间段与指标导出 CSV/PDF，含轨迹、速度、关节角和角速度。
- 建议页使用趋势、session 汇总和个人基线展示训练建议。

## 系统设置与本机数据

- RTSP 默认账号、端口、路径、预览/主码流 FPS、NVR 回放模板。
- 12 路相机、标定、分析来源/目标 FPS/最大流数/自动降级、模型精度和采集 FPS。
- 本机视频资产根目录、容量阈值、保留天数、清理候选；清理需确认且只登记清理状态，不删训练记录。
- 摄像头 JSON 模板导入/导出；模板可能含 RTSP 密码。
- `nas://` 到 Windows 盘符/UNC 的根映射。

## 服务端能力（无独立 Web UI）

- JWT 登录、健康检查。
- 人员、样本/embedding、比赛/场次/参赛关系、动作标准、训练任务、session、复核、手动动作、批注、趋势、基线。
- 视频资产查询与清理状态登记。
- 单视频任务、完整批次/运行、取消/重试/激活、帧窗口读取。
- worker 领取、心跳、gallery、分块提交和完成上报。

## 重编排建议：必须拆开的区域

1. **实时采集**：RTSP 预览、机位、开始/暂停/停止、当前参与者和实时框。
2. **本地视频分析**：文件选择、视频探测、分析启动/进度/结果与保存；不能继续借用“开始采集”。
3. **完整批处理**：12 路 NAS/Ubuntu DeepStream，独立于单视频和实时页。
4. **任务与结果**：任务中心、历史检索、报告、复盘、导出集中管理。
5. **基础资料与设置**：人员、ReID 样本、比赛、动作标准、相机、存储、连通测试独立管理。
