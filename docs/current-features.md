# 当前已完成功能概览

## 1. 视频采集

- 支持最多 12 路 RTSP 预览和主视图播放。
- 支持离线视频导入、文件校验、训练 session 保存和历史回看。
- 支持 RTSP 重连、UDP/TCP fallback、NVR 回放引用和视频资产索引。

## 2. 运动员检测与身份识别

实时主流程使用 `YOLO26x → PersonViT/MSMT17 ReID`：

- YOLO26x 只检测 COCO `person`，输出检测框和置信度。
- PersonViT 为检测框生成 768 维归一化 embedding。
- 当前 session 最多四名参与者进入 gallery，按余弦相似度匹配 athleteId。
- 候选接近时标记 `ambiguous`；无匹配时保留 `unknown`。
- 每个机位独立维护 trackId，机位之间可通过 athleteId 识别为同一运动员。
- 支持当前机位 track 的人工身份绑定，作为低置信度和未知身份兜底。
- 主视频覆盖层绘制检测框、身份标签和 trackId。

## 3. 样本库

- 人员管理页支持 ReID 样本图片添加、查看和删除。
- 上传样本时生成 PersonViT embedding，并保存模型版本、预处理版本和维度。
- 只加载与当前模型版本和预处理版本一致的 embedding；模型升级后旧向量自动失效，需要重新生成。

## 4. 训练记录与历史兼容

- 新训练保存视频、参与者、检测框、机位、trackId、身份状态和身份置信度。
- 新训练不生成姿态关键点、动作评分、动作 repetition 或虚假的基线结果。
- 旧 `participant_pose_frames`、动作、评分和姿态复盘读取路径保留，便于历史记录兼容。
- FastAPI/PostgreSQL 继续保留旧字段，历史数据可继续查询和导出。

## 5. 明确不提供的能力

当前版本不提供实时姿态关键点、3D 姿态、骨架刷新、轨迹拼接、姿态评分、动作纠错和自动动作计数。动作标准和历史复盘界面仅作为旧数据兼容入口保留。
