# 当前已完成功能概览

本文档简要说明 iSkating Coach 当前已经完成的主要软件能力，方便快速了解项目现状。内容只做功能层面的概括，不展开具体实现细节。

## 1. 多路摄像头采集与显示

软件已经支持面向训练场景的多路摄像头接入。用户可以配置多路 RTSP 摄像头，并在主界面中同时查看多个机位的预览画面。

当前已具备：

- 最多 12 路摄像头预览。
- 主视图显示选中机位的高清画面。
- 摄像头公共参数和单路相机参数配置。
- 采集开始、暂停、停止等基础控制。
- 离线视频源的基础回看与分析支持。

## 2. 实时视频播放与训练采集

软件已经具备训练采集主流程。用户完成摄像头和训练上下文配置后，可以启动一次训练采集，并在界面中查看训练过程中的视频、状态和统计信息。

当前已具备：

- 训练开始前选择运动员、教练、动作标准和训练目标。
- 采集过程中显示训练时长、动作数量和实时分数。
- 支持停止采集后保留本次训练数据，便于继续保存记录。
- 支持视频状态提示和基础异常提示。

## 3. AI 姿态识别与可视化

软件已经接入人体姿态识别能力，可以对训练视频进行实时分析，并将结果展示在界面中。

当前已具备：

- 基于人体关键点的 2D 姿态识别。
- 可选的 3D 姿态结果补充。
- 主视频画面上的姿态叠加显示。
- 独立骨架视图展示。
- 多机位训练轨迹可视化。
- 基于摄像头覆盖范围的全场轨迹拼接。

## 4. 动作评分与训练反馈

软件已经具备基础动作评分和纠错反馈能力。系统会根据识别到的姿态结果计算训练表现，并生成面向训练复盘的评价信息。

当前已具备：

- 姿态标准度评分。
- 动作标准权重和阈值评分。
- 动作次数识别。
- 最好分、平均分、目标完成情况等训练指标。
- 错误项和纠正建议生成。
- 不同动作标准的本地维护能力。

## 5. 训练记录与历史复盘

软件已经可以保存训练记录，并在历史页面中查看训练摘要、动作明细和复盘入口。

当前已具备：

- 本地保存训练 session。
- 保存动作实例、分数、错误项、反馈和视频引用。
- 历史训练记录展示。
- 训练统计摘要。
- 教练批注保存。
- 复盘校准入口。
- 支持人工修正动作有效性、分数和备注。

## 6. 报告与建议

软件已经具备训练结果输出和后续训练建议能力，方便教练或训练人员进行阶段性跟踪。

当前已具备：

- Markdown 训练报告导出。
- CSV 动作明细导出。
- PDF 复盘报告导出。
- 基于最近训练记录的建议生成。
- 最近 7 天和 30 天训练趋势统计。
- 弱项分析和下次训练建议。

## 7. 本地配置与数据持久化

软件已经具备本地配置和训练数据保存能力，不依赖独立服务端即可运行主要训练流程。

当前已具备：

- 摄像头配置本地保存。
- 采集偏好本地保存。
- 训练业务数据保存到本地数据库。
- 默认运动员、教练和动作标准数据初始化。
- 旧训练历史数据兼容迁移。

## 8. 当前软件形态

当前软件已经形成一个可运行的 Windows 桌面训练辅助应用，核心能力覆盖了从摄像头配置、训练采集、AI 姿态分析、实时评分，到训练保存、历史复盘和报告导出的主要闭环。

整体上，当前版本更接近一个面向本地训练场景的原型到可用系统阶段：核心流程已经打通，后续重点会是结合真实训练数据继续校准动作标准、优化识别准确性、完善部署说明和提升长期使用体验。
